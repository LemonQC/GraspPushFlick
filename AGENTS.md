# GraspPushFlick / TRO-APFG — project instructions

## Scope
Research target: IEEE T-RO, active perception, pushing, physical flipping/reorientation, and 6-DoF grasping for retrieval of a designated object in clutter. Flip means a physical change in the object's 3D orientation/support state, not reverse planning. No object rearrangement objective, VLA, cross-embodiment learning, or online LLM API. Reverse grasp-conditioned planning is a separate RA-L project. No novelty or formal performance claims until evidence is available.
