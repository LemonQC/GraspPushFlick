# E1 协议与执行边界

协议文件 `configs/m1/e1_protocol_v2.json` 已冻结，状态 **NOT_RUN**。4类（Direct/C1/C2/C3）×2种子（2026112201/2026112202）×2目标（sugar box/soup can）=16个实例，每实例同条件比较 DIRECT_GRASP、PUSH_GRASP、FLIP_GRASP、VIEW_GRASP，共64个未来开发比较 episode。各臂最多一个准备动作、一次抓取，最多检查8个GraspNet候选；不强制四技能顺序。C4只开放配置/查看，E2/E3与训练均NOT_RUN。

v1在首次pilot前冻结，保留原件。pilot暴露提示颜色混淆、腕部盲区、夹爪壳体退距与自然落定时长问题，因此另存v2，未覆盖v1，也未更改数值成功门槛。v2规范化内容SHA256（去掉自身哈希字段后，以sorted JSON编码）为 `1fe314d1b6c90f6404828c5bae64f8db687c58ed0a7de6bf067ad3f2ba55750b`；文件自身字节哈希另见证据manifest。生成器拒绝静默改写不同的冻结协议。

固定条件为同一真实资产、初始化姿态/种子、相机初始视角、RGB-D分辨率、物理参数、GraspNet权重、候选预算、六轴/80mm夹爪模型和碰撞检查方式。每实例的初始配置内容哈希列在协议中。黄色包使用显式可见RGB提示，其他物体使用明确任务区域；区域可能包含遮挡物，不以仿真GT做完美实例掩膜。不能以不同臂的额外oracle信息换取优势。ORACLE_DIAGNOSTIC只能单列诊断，不能混入RGBD结果。

| 度量 | 冻结门槛/定义 |
|---|---|
| 初始稳定 | 最后约1s真实姿态，至少.9s覆盖；位移<2mm且转动<.01rad；最多4次额外1s自然落定，无状态重置 |
| Push物理事件 | 测得机器人目标接触且XY位移>3cm；另记旋转、干扰物运动，倾倒不得称作纯平移 |
| Flip物理事件 | 局部重力方向变化≥35°且旋转向量水平分量≥25°；真实目标接触、最终新支撑稳定、环境支撑接触、机器人撤离；纯yaw不计 |
| Active动作检查 | 无执行错误、物体位移<2mm；另存外参/真实RGB-D，动作完成不等于有信息收益 |
| 完整取出 | 目标所有源外接几何y>.30m、高度相对初始>.10m，双指真实接触持续1s；干扰物COM不得跌破−.05m |
| 成本 | 动作数、关节/EE/物体路径、仿真时长、网络/检查墙钟、执行墙钟；额外观察动作必须显式记账 |
| 失败 | 无可见目标、无可行原始候选、IK/碰撞/跟踪失败、错误目标、掉落、未完全取出均保留；不删除失败种子 |

场景族是生成假设，不是“必须推/翻/观察”的标签。必须在同一物理实例比较四臂的完整取出结果才能审查机制；Direct已成功的实例不得称为push/flip必要。先报告每实例、动作和失败原因，未经足够重复与设计审查不报告论文统计结论。初始落定后实际位姿必须一并记录，不能只根据生成参数宣称场景合格。

当前17次smoke只验证接口/物理路径，包含开发中修复与单独ORACLE翻转，不构成这64个episode的任何替代。`scripts/run_m1.sh`可执行各臂入口（`grasp/push_grasp/flip_grasp/active_grasp`），但本轮未启动完整矩阵，尚无臂间收益或机制必要性结论。继续前应先核验不利姿态下的Flip接触策略、目标提示关联和动作参数；不要把接口支持等同于任务完成。
