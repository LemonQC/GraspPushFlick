# M0 基线范围

目标是复杂三维杂乱场景中指定目标的完整取出。Active 通过真实相机运动改善观测；Push 改变接触与遮挡；Flip 是倾倒、滚转或翻身等物体三维姿态和支撑关系改变；Grasp 为平行双指夹爪的空间六维抓取及完整移出。

M0 只建立并验证环境、资产、相机、机械臂控制和记录。关节正弦目标和夹爪开合只是执行器诊断，不是协同操作策略。真实掉落物体使用物理步进，不通过 rollout 中重置状态、穿模摆放、瞬移抓取或添加人工附着约束制造成功。初始化可以设置状态，动作执行阶段只能通过控制器和物理引擎推进。

不研究重排目标、VLA、跨本体学习或在线大模型接口。反向抓取条件规划属于独立 RA-L 工作，不在本项目实现。本轮不训练模型、不提出最终创新算法、不声称性能优势。

当前控制代码属于诊断 ORACLE 模式，可读关节、末端、物体真值用于评测和碰撞记录；未来 RGBD 决策模式不得隐式使用这些真值。观测和评测必须清楚分开。YCB 与 GraspNet 的同一物体重复扫描不能用作独立未见测试物体。
