# Reproducibility

M1 SR5 scene/action extension (2026-11-22) uses `scripts/run_m1.sh`; see [actual commands and failures](M1_REPORT_ZH.md) and [frozen E1 protocol](E1_PROTOCOL_ZH.md). It reuses the installed environment and assets. This SR5 path runs CPU PhysX at480Hz with RTX RGB-D recording30fps and explicit PhysX-to-USD rendering publication; the original Franka M0 settings below remain historical, not SR5 settings. Save exact scene.json, run_config.json and local artifacts per unique run. Public metadata/checksums are under evidence/m1/. E1 comparison is NOT_RUN; independent development smokes cannot be counted as formal episodes.

Use the current repository root as PROJECT_ROOT and source scripts/project_env.sh. The parent HOME and desktop authentication remain unchanged. Simulator children use project-local HOME and Kit portable-root; CUDA, GL and OptiX caches each have an explicit local path. No system driver upgrade or user shell edits are part of installation.

The measured stack is RTX 3090 / NVIDIA 535.230.02, Ubuntu 20.04.6 / GLIBC 2.31, an existing Isaac Sim 4.5 binary distribution, Isaac Lab release v2.0.2 at b5fa0eb031a2413c182eeb54fa3a9295e8fd867c, Python 3.10.22, torch 2.5.1/cu118 and torchvision 0.20.1. Exact package and binary versions, local hashes and pip freeze are under outputs/environment_check/. This does not validate the requested 5.1/2.3.1 pip stack on this host.

Run check_system.sh, setup_isaac.sh, download_isaac_assets.sh, download_ycb.sh, bundled_python.sh scripts/convert_assets.py, then bundled_python.sh scripts/check_asset_integrity.py. The binary and asset source roots may be supplied with APFG_ISAAC_BINARY_SOURCE / APFG_ISAAC_ASSET_SOURCE. See configs/constraints.txt. The setup fingerprint skips already verified installations; downloads retain partial files, use bounded retries/TLS and verify receipt hashes/archive integrity.

GUI and Headless use the same AppLauncher, scene, controller, sensors, recorder and acceptance rules. GUI omits --headless; both include --enable_cameras. Scene selection is --scene s1/s2, seed is 20261120. Clutter defaults to 4800 physical steps; other smokes default to 1200. Physics is 120 Hz, recording 30 FPS, default resolution 1280x720. Some measured Headless cases explicitly use 640x480. Lower recording rates must divide 120 and the requested step count must contain whole recording intervals.

World.step(render=True) integrates rendering_dt/physics_dt substeps. The runner therefore invokes it once per capture interval and validates actual SDK physical step count and elapsed simulation time. Video frame timestamps use measured simulation time, alongside wall monotonic times. It does not infer physical steps from Python loop iterations. Every MP4 is fully decoded for count/FPS/duration validation, and capture gaps are explicit.

Object poses are set only during initialization. Robot rollout uses joint targets, not repeated state resets. S1 drops six objects to the table; S2 uses a documented physical retaining tray (0.26x0.26 m interior, 0.30 m walls) and free fall. Validation uses measured rigid-body pose stability, real contact forces, elevated final geometry and raw PhysX object contact pairs. SDK velocities are preserved separately; pose-derived speeds prevent stale sleeping-body metadata from masquerading as motion. Ground truth is used only for diagnostics/ORACLE evaluation, not as an unstated RGBD policy input.

The camera near plane is explicitly 0.01 m. Wrist extrinsics are attached to panda_hand and measured during real joint motion; workspace visibility is checked. RGB-D, depth in meters and uint16 millimeter PNG, instance labels, calibration, target optical-frame PLY, multiview PNG, commands and joint/EE/object/contact telemetry are saved in unique UTC+suffix run directories. Third-person, fixed and wrist recordings are real rendered frames. Interactive previews are distinguished from formal smokes and never replace formal acceptance results.

--offline disables Kit registry lookups and anonymous telemetry settings, while all scene USD/texture paths remain project-local. A camera/robot/YCB smoke with this flag actually passed. Host networking was not disconnected; this is not an OS network-isolation test.

Run bash scripts/run_m0.sh for the ordered workflow. It stops on failed prerequisites and refreshes measured summaries through an EXIT trap. CPU checks use scripts/verify_local.sh, unittest discover -s tests -v, compileall and bash -n. Seven CPU tests cover archive safety, readiness and pose stability; they do not replace GPU runs. Actual modules were also executed individually with saved commands/run IDs.

Original outputs and full videos stay local under outputs/environment_check/runs/<run_id>/. Convenience names at outputs/environment_check/ link to immutable run files and have provenance receipts. evidence/ contains sanitized metrics, local artifact hashes and a few JPEG-encoded sensor frames with source hashes. Failed, blocked and successful historical runs are retained. Latest formal measurements determine gates; GitHub synchronization must be verified before APFG_M0_READY is true. Physical parameters remain estimated, and complex cavity/thin-tool contact fidelity requires further calibration before later research claims.
