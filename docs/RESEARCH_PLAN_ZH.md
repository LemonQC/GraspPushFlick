# 研究路线与证据边界

研究任务为杂乱三维环境中的指定目标取出，候选动作空间为主动感知、推动、真实翻转和六维抓取。研究评价必须同时覆盖接触关系、可见性、不确定性、动作代价和完整取出结果。Flip 应改变物体的三维姿态或稳定支撑状态，单纯平面偏航不能代表完整翻转能力。

阶段按依赖推进：M0 环境与真实资产验证；M1 统一执行器、场景和记录；M2 主动视觉；M3 推动；M4 倾倒/滚转；M5 抓取与完整取出；M6 动作协同决策；M7 已发表基线复现和科学贡献评估。M0 尚未通过时不提前进行后续训练或宣称算法创新。

M0 采用独立物体下落测试、机械臂与夹爪运动、固定/腕部 RGB-D、平面密集场景 S1 和自然掉落形成的三维堆叠 S2。正式通过必须来自自动测量：至少 240 个物理步、重力下落、真实接触、持续稳定、控制误差、相机随末端的刚性外参关系，以及可解码的视频。

S1/S2 使用可复现随机种子，保存初始条件、真实模拟轨迹、物体身份和参数版本。正式实验要同时保存成功和失败，不只挑选成功片段。比较未见物体前，先处理跨数据集同物体扫描重叠。

当前已实际验证 M0 的物理、控制、双相机、13 种真实物体和两类 GUI/Headless 场景；最终状态见 M0 报告。静态网格转换、下载成功、GPU 被 nvidia-smi 列出，均不能推出 PhysX、RGB-D、机械臂运动或翻转策略已通过。

com3 Baseline阶段已完成E1v3固定16次、12次真实采集、4次DQN online交互与六方法各2次统一物理holdout。配对初态有效，但E1没有出现Direct失败而准备后取出成功的实例；C2翻转未改变支撑姿态，C1/C3直接抓已有成功。因此机制资格NO_GO，不能以堆叠四技能或小样本DQN结果宣称T-RO贡献。BC/DP共同示范只有6次成功，缺Push/Flip成功支持；实际小训练和checkpoint链路通过不代表下一轮规模化训练已获资格。详见 BASELINE_PARALLEL_REPORT_ZH.md，下一步先修正原语、动作后目标关联与机制场景，再另存协议审查，不回填旧E1结果。
